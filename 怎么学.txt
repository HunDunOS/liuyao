  一、30 秒：这是什么
  ────────────────────────────────────────────────────────────────

  一门自己写的语言。源码里【只有字母和数字】，一个标点都不打。

      · 词（指令）= 六爻：64 条，小写两字母      tt 定义函数  nn 循环  nr 条件
      · 类型 = 五行：大写，J M S H T + 25 个配对
      · 符号 = 数字：两位一组，01 ( 02 ) 08 { 09 }
      · 注释 = rd，后面整段中文随便写（中文只给人看）

  编译器（lyc）自己就是用这门语言写的 —— 它能编译它自己（自举）。


  二、怎么装（挑你那个平台）
  ────────────────────────────────────────────────────────────────

  要两样东西：一个 C 编译器、一个 python3。

  ▍Linux
      sudo apt install gcc python3        # Debian/Ubuntu
      sudo pacman -S gcc python           # Arch

  ▍macOS（苹果）
      xcode-select --install              # 自带 clang 和 python3
      brew install qemu                   # 想跑 x86-64 程序才要

  ▍Windows
      装 Git for Windows（带 Git Bash），从 Git Bash 里跑：
          sh 编.sh 示例/三角.ly
      或者装 MSYS2，pkg install 里装 gcc 和 python3。

  ▍Android（Termux）
      pkg update
      pkg install clang python
      pkg install qemu-user-x86-64        # 手机是 ARM，跑 x86-64 程序要它

  ▍其他 Unix          基本上 cc + python3 就够了


  三、第一个程序
  ────────────────────────────────────────────────────────────────

  新建 你好.ly：

      tt 主() -> u32 {
          st dd "你好，六爻"
          st dd "\n"
          zz 0
      }

  跑：

      sh 编.sh 你好.ly

  出来：

      你好，六爻


  四、词表（先记这 10 个）
  ────────────────────────────────────────────────────────────────

      tt  乾乾   定义函数
      tz  乾兑   定义变量
      th  乾离   定义常量
      tn  乾震   定义结构体
      zz  兑兑   返回值
      nn  震震   循环开头（不带条件 = 无限循环）
      nr  雷山   条件分支（如果）
      ns  雷水   循环跳出（break）
      nf  雷风   循环继续（continue）
      st  水天   写屏幕      st dt 值（写整数） · st dd 串（写字符串）

      rd  山地   注释（这一行后面全给人看）
      qj  全局   全局变量
      wx  危险块 里面才允许裸指针解引用 / 取地址

  算术也用卦（不打 + - * / %）：

      ht 加   hz 减   hh 乘   hn 除   hf 取模
      hs 位与  hr 位或  hd 位异或   << >> 移位


  五、类型用五行（首字母缩写）
  ────────────────────────────────────────────────────────────────

      J 金 4 字节（数值）    M 木 8 字节（指针）    S 水 1 字节
      H 火 4 字节（结构体）  T 土 4 字节（空）
      JJ JM JS JH JT … TT   一共 5×5 = 25 个配对

      老名字 u8 u16 u32 … 也认（兼容）。


  六、循环按这个写法（推荐）
  ────────────────────────────────────────────────────────────────

      nn {
          nr 条件 { ns }        条件成立就跳出
          循环体
      }

  例（打印 1 / 12 / 123）：

      tt 主() -> u32 {
          tz 行: u32 = 1
          nn {
              nr 行 > 3 { ns }
              tz 列: u32 = 1
              nn {
                  nr 列 > 行 { ns }
                  st dt 列
                  列 = 列 ht 1
              }
              st dd "\n"
              行 = 行 ht 1
          }
          zz 0
      }


  七、数字标点（会把标点都换掉的话）
  ────────────────────────────────────────────────────────────────

      01 (    02 )    03 "    04 "    05 ;
      06 换行   07 {    08 {    09 }

  例：  tt 主0102 08 st dd 03你好04 09
  等于：tt 主() { st dd "你好" }

  用工具 工具/符号.py 还原：
      python3 工具/符号.py 程序.数字          # 看还原结果
      python3 工具/符号.py 程序.数字 -o 出.ly # 存成六爻源码


  八、怎么造工具（这是这门语言的真本事）
  ────────────────────────────────────────────────────────────────

  编译器自己就是用六爻写的：
      编译器/词法.ly    词法分析（466 行）
      编译器/语法.ly    符号表   （351 行）
      编译器/出码.ly    出码     （1147 行）
      编译器/编译器.ly  三个拼起来 = 完整的编译器

  ★ 它能编译它自己：stage1 编 编译器.ly，吐出的 19607 行汇编和 C 写的版本
    逐字节一样。这就是"能造轮子"的证据。

  你自己想写一个工具（比如把数字标点还原成标点），照 示例/数字还原.ly 抄就行。


  九、现在能用什么 / 还不能用什么（老实说）
  ────────────────────────────────────────────────────────────────

  ✅ 能
      · 写程序、编、跑（Linux/macOS/Windows 的 x86-64 电脑原生跑）
      · 手机/苹果 M 芯片：装 qemu-user 跑
      · 编译器自己编译自己
      · 九个模块（盘/压缩/机器/包/壳/编辑器/桌面/主终端）链接成一个程序

  ⬜ 还不能
      · 手机（arm）上【原生】跑 —— 编译器现在只出 x86-64 码。
        要原生跑得等 arm-64 / arm-32 后端做好（在做）
      · 图形 / 桌面（绘点 绘块 绘字 还没搬成 64 位）
      · 中文上屏（现在是文本模式，只有西文字库）
      · 裸机（现在跑在操作系统上，不是自己开机）


  十、目录里有什么
  ────────────────────────────────────────────────────────────────

      编.sh            一键：源码 → 可执行 → 跑
      编译器/          lyc.c（C 写的 stage0） + 词法/语法/出码.ly（六爻写的 stage1）
      工具/            符号.py（数字标点还原） · 小链接.py（可重定位对象 → 可执行）
      宿主/            宿主64.s（运行时源码） · 预造/（造好的，手机上也够用）
      示例/            能跑的例子，抄着改
      文档/            六爻表 · 五行分工 · 写法约定


  十一、卡住了怎么办
  ────────────────────────────────────────────────────────────────

  · 报 "名字不存在：xxx"      → 那个词不是关键字。查 文档/六爻表_定稿.txt
  · 报 "期望 '('"              → 括号没打（数字标点里 01 = (  02 = )）
  · 报 "名字太长"              → 编译器给名字留 900 字节（约 100 个汉字）
  · 手机上说跑不了            → pkg install qemu-user-x86-64
  · 想看编译器自己怎么写的     → 编译器/词法.ly 从第一行看起，都是 rd 中文注释

★ 一条要紧的（安卓/共享盘会踩）
────────────────────────────────────────
别在【安卓的共享盘 / 网盘挂载目录】里直接跑。

    /sdcard/... 这一类是 noexec（不让执行程序）
    在那种目录里跑，会报：
        Permission denied

必须【抄到能执行的地方】再跑：
    手机 Termux:   cp -r 六爻工具链 ~/ && cd ~/六爻工具链
    电脑:          随便找个磁盘目录，别在网盘挂载点里
