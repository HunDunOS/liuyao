                        六爻(LiuYao) 语言使用教程

文件类型: .ly （编译型系统编程语言）
编译器: lyc (stage0 C种子 → 自举六爻版)
哲学: 道生一，一生二，二生三，三生万物
      混沌→道→两仪→四象→八卦→六四(64 syscall)

================================================================================
一、设计哲学
================================================================================

六爻以八卦为基础，8个基本符号对应8个字母:

  乾(天) = t    兑(泽) = z    离(火) = h    震(雷) = l
  巽(风) = f    坎(水) = s    艮(山) = r    坤(地) = d

两爻相重成64卦，每卦对应一个关键字/运算符。
64 = 8×8，完美对应操作系统的64个syscall。

================================================================================
二、数字标点映射（纯血六爻，零C符号）
================================================================================

  01 = (      左括号
  02 = )      右括号
  03 = "      左双引号
  04 = "      右双引号
  05 = ;      分号
  06 = /      斜杠
  07 = \      反斜杠
  08 = {      左花括号
  09 = }      右花括号
  00 = #      井号

两种写法等价，编译器自动还原:
  tt 主() -> u32 { tz x 5 zz x }
  tt 主01 02 -> u32 08 tz x 5 zz x 09

三、64关键字完整速查表
================================================================================

【天字头 t_ （声明类）】
  tt  乾乾  定义函数      tz  乾兑  定义变量
  th  乾离  定义常量      tn  乾震  定义结构体
  tf  乾巽  定义数组      ts  乾坎  定义指针
  tr  乾艮  类型别名      td  乾坤  导入模块

【泽字头 z_ （函数类）】
  zt  泽天  调用函数      zz  兑兑  返回值
  zh  泽火  递归调用      zl  泽雷  回调函数
  zf  泽风  闭包          zs  泽水  匿名函数
  zr  泽山  方法调用      zd  泽地  系统调用

【火字头 h_ （运算类）】
  ht  火天  加法          hz  火泽  减法
  hh  离离  乘法          hl  火雷  除法
  hf  火风  取模          hs  火水  位与
  hr  火山  位或          hd  火地  位异或

【雷字头 l_ （控制类）】
  lt  雷天  无条件跳转    lz  雷泽  相等跳转
  lh  雷火  不等跳转      ll  震震  循环开头
  lf  雷风  循环继续      ls  雷水  循环跳出
  lr  雷山  条件分支      ld  雷地  开关分支

【风字头 f_ （输入类）】
  ft  风天  读键盘        fz  风泽  读文件
  fh  风火  读内存        fl  风雷  读端口
  ff  巽巽  读数组        fs  风水  读结构体
  fr  风山  读指针        fd  风地  读常量

【水字头 s_ （输出类）】
  st  水天  写屏幕        sz  水泽  写文件
  sh  水火  写内存        sl  水雷  写端口
  sf  水风  写数组        ss  坎坎  写结构体
  sr  水山  写指针        sd  水地  写日志

【山字头 r_ （结构类）】
  rt  山天  进入作用域    rz  山泽  退出作用域
  rh  山火  类型转换      rl  山雷  类型检查
  rf  山风  引用          rs  山水  解引用
  rr  艮艮  空操作        rd  山地  注释

【地字头 d_ （数据类）】
  dt  地天  整数          dz  地泽  浮点数
  dh  地火  字符          dl  地雷  布尔值
  df  地风  数组字面量    ds  地水  结构体字面量
  dr  地山  空值          dd  坤坤  字符串

四、类型系统
================================================================================

  整数: u8 u16 u32 u64 i8 i16 i32 i64
  指针: *类型名
  空类型: z
  数组: 类型名[长度]

  五行单字类型（可混用）:
    J 金 = 4字节数值
    M 木 = 8字节指针
    S 水 = 1字节
    H 火 = 4字节结构
    T 土 = 4字节空

================================================================================
五、基础语法
================================================================================

5.1 函数定义
────────────────────────────────────────
  tt 函数名(参数1: 类型, 参数2: 类型) -> 返回类型 08
      函数体
  09

  示例:
  tt 主() -> u32 08
      tz x 5
      zz x
  09

5.2 变量声明
────────────────────────────────────────
  tz 变量名 初值          简化写法
  tz 变量名 = 初值        完整写法
  tz 变量名: 类型 = 初值  带类型

  示例:
  tz x 5
  tz y = x ht 3
  tz 名字: dd = "hello"

5.3 常量声明
────────────────────────────────────────
  th 常量名 = 值

5.4 数组声明
────────────────────────────────────────
  tf 数组名[长度]
  tf 数组名[长度] = 初值

5.5 函数调用
────────────────────────────────────────
  zt 函数名(参数1, 参数2)

  示例:
  zt _rt_puts(01 "Hello!" 02)
  zt _rt_puti(01 x 02)

5.6 返回值
────────────────────────────────────────
  zz 表达式

5.7 循环
────────────────────────────────────────
  ll 08
      循环体
  09

  计数循环示例:
  tz i 0
  ll 08
      lr i == 10 08 ls 09
      zt _rt_puti(01 i 02)
      tz i = i ht 1
  09

5.8 条件分支
────────────────────────────────────────
  lr 条件 08
      条件为真时执行
  09

  示例:
  lr x > 5 08
      zt _rt_puts(01 "x大于5" 02)
  09

5.9 相等/不等跳转
────────────────────────────────────────
  lz 值1 值2 08 ... 09    如果相等则执行
  lh 值1 值2 08 ... 09    如果不等则执行

5.10 break / continue
────────────────────────────────────────
  ls    跳出循环
  lf    继续下一次循环

5.11 注释
────────────────────────────────────────
  rd 注释内容（行内注释到行尾）

八、编译运行
================================================================================

8.1 三步编译法
────────────────────────────────────────
  步骤1: 编译为目标文件
    ./lyc -c -对象 源文件.ly -o 输出.o

  步骤2: 链接
    python3 工具/小链接.py 输出.o 可执行文件

  步骤3: 运行
    chmod +x 可执行文件
    ./可执行文件

8.2 完整示例
────────────────────────────────────────
  ./lyc -c -对象 hello.ly -o hello.o
  python3 工具/小链接.py hello.o hello
  ./hello

8.3 编译为汇编（调试用）
────────────────────────────────────────
  ./lyc -c 源文件.ly -o 输出.s
  as --64 输出.s -o 输出.o
  ld -m elf_x86_64 -o 可执行文件 输出.o 宿主/宿主64_direct.o

8.4 无汇编器机器
────────────────────────────────────────
  小链接.py自动检测，没有as就用 宿主/预造/ 下的预造运行时。

8.5 编译种子编译器
────────────────────────────────────────
  gcc lyc.c -o lyc -O2
  （注意: 编码器.c被lyc.c #include，不要单独编译编码器.c）

九、完整示例程序
================================================================================

9.1 Hello World
────────────────────────────────────────
  tt 主() -> u32 08
      zt _rt_puts(01 "Hello, World!" 02)
      zz 0
  09

9.2 计算 3 + 4 × 2
────────────────────────────────────────
  tt 主() -> u32 08
      tz x 3 ht 4 hh 2
      zt _rt_puts(01 "3 + 4 * 2 = " 02)
      zt _rt_puti(01 x 02)
      zt _rt_putc(01 10 02)
      zz x
  09
  输出: 3 + 4 * 2 = 11

9.3 循环打印 0 到 9
────────────────────────────────────────
  tt 主() -> u32 08
      tz i 0
      ll 08
          lr i == 10 08 ls 09
          zt _rt_puti(01 i 02)
          zt _rt_putc(01 32 02)
          tz i = i ht 1
      09
      zt _rt_putc(01 10 02)
      zz 0
  09

9.4 数组求和
────────────────────────────────────────
  tt 主() -> u32 08
      tf arr[5]
      arr[0] = 10
      arr[1] = 20
      arr[2] = 30
      arr[3] = 40
      arr[4] = 50
      tz sum 0
      tz i 0
      ll 08
          lr i == 5 08 ls 09
          tz sum = sum ht arr[i]
          tz i = i ht 1
      09
      zt _rt_puts(01 "sum = " 02)
      zt _rt_puti(01 sum 02)
      zt _rt_putc(01 10 02)
      zz sum
  09

十、常见问题
================================================================================

Q: 为什么用数字标点(01 02 08 09)而不是(){}?
A: 为了纯血六爻，不含任何C语言的符号。两种写法都支持。

Q: lyc.c 和 编码器.c 是什么关系?
A: 编码器.c 被 lyc.c #include，不能单独编译。
   正确: gcc lyc.c -o lyc -O2
   错误: gcc lyc.c 编码器.c -o lyc

Q: 小链接.py 报错"没有x86-64汇编器"?
A: 确保 宿主/预造/ 下有 宿主64.elf 和 宿主64.bin。

Q: 支持哪些平台?
A: 当前 x86-64 Linux。目标是 hundunOS 自研操作系统。
