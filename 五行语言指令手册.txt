一、快速开始
================================================================================

  编译解释器:
    ./lyc -c -对象 wuxing.ly -o wuxing.o
    python3 工具/小链接.py wuxing.o wuxing

  运行脚本:
    ./wuxing 脚本.wx

  注意: 只接受 .wx 后缀，其他后缀报错

  Hello World:
    jj "Hello, World!"

================================================================================
二、类型与变量
================================================================================

  变量只能存整数。字符串用双引号包裹，只能用于打印和shell命令。

  变量赋值:
    tj 变量名 值
    示例: tj x 42
          tj name 100

  tm 是 tj 的别名，用法完全一样:
    tm y 99

  变量打印:
    jj 变量名
    示例: jj x   →  42

================================================================================
三、输出指令
================================================================================

3.1 jj — 打印
  语法: jj "字符串"  或  jj 数字/变量
  功能: 打印字符串或整数值到屏幕
  示例:
    jj "你好"
    jj 42
    tj x 100
    jj x

3.2 jm — 打印并清零
  语法: jm 变量
  功能: 打印变量值然后将变量清零
  示例:
    tj x 50
    jm x    → 打印50，x变为0

3.3 jd — 调试打印
  语法: jd "调试信息"
  功能: 打印调试信息（带调试标记）

================================================================================
四、数学运算
================================================================================

4.1 复合赋值
  mj 变量 值   加等 (变量 = 变量 + 值)
  mm 变量 值   减等 (变量 = 变量 - 值)
  ms 变量 值   乘等 (变量 = 变量 * 值)
  md 变量 值   除等 (变量 = 变量 / 值)
  mt 变量 值   取模等 (变量 = 变量 % 值)

  示例:
    tj x 10
    mj x 5    → x=15
    mm x 3    → x=12
    ms x 2    → x=24
    md x 4    → x=6
    mt x 4    → x=2

4.2 表达式（用于条件和赋值）
  ht  加法    a ht b  = a + b
  hz  减法    a hz b  = a - b
  hh  乘法    a hh b  = a * b
  hl  除法    a hl b  = a / b
  hm  取模    a hm b  = a % b

  示例:
    tj a 3
    tj b 4
    tj c a ht b    → c=7
    tj d a hh b    → d=12

================================================================================
五、比较运算
================================================================================

  比较结果: 真=1 假=0

  sj a b   相等 (a == b)
  sm a b   不等 (a != b)
  ss a b   大于 (a > b)
  sd a b   小于 (a < b)
  st a b   大于等于 (a >= b)

  示例:
    tj x 10
    sj r x 10    → r=1
    ss r x 5     → r=1
    sd r x 20    → r=0

七、条件分支
================================================================================

7.1 Xj — if 开始
  语法: Xj 条件表达式
  功能: 条件为真时执行if块，否则跳到Xt
  示例:
    tj x 10
    Xj x > 5
    jj "x大于5"
    Xt

7.2 Xm — else if
  语法: Xm 条件表达式
  功能: 上一个Xj/Xm条件为假时，判断本条件
  示例:
    tj x 3
    Xj x > 5
    jj "x>5"
    Xm x > 0
    jj "x>0且x<=5"
    Xt

7.3 Xt — if/else if 结束
  语法: Xt
  功能: 标记条件块结束

7.4 dd — 单行if
  语法: dd 条件 指令
  功能: 条件为真时执行单行指令
  示例:
    tj x 10
    dd x > 5 jj "x很大"

八、循环
================================================================================

8.1 for循环 (Cj...Ct)
  语法:
    Cj 初始化
    Cm 条件
    Cs  (占位，可省略)
    Cd 增量
    Ct  (for结束，自动跳回Cm)

  示例:
    Cj i 0
    Cm i < 5
    jj i
    Cd i 1
    Ct
    jj "循环结束"

  说明:
    Cj 设置循环变量初值
    Cm 评估条件，为假则跳到Ct之后
    Cd 循环变量增量
    Ct 跳回Cm重新评估条件

8.2 while循环 (ll...ld)
  语法:
    ll 条件表达式
    ...循环体...
    ld  (while结束，自动跳回ll)

  示例:
    tj i 0
    ll i < 5
    jj i
    mj i 1
    ld
    jj "while结束"

8.3 Dj — break (跳出循环)
  语法: Dj
  功能: 跳出当前for/while循环，跳到Ct/ld之后
  示例:
    Cj i 0
    Cm i < 10
    Xj i == 5
    Dj
    Xt
    jj i
    Cd i 1
    Ct

8.4 Dm — continue (跳过本次循环)
  语法: Dm
  功能: 跳回循环开头，跳过本次循环剩余部分
  示例:
    Cj i 0
    Cm i < 5
    Xj i == 2
    Dm
    Xt
    jj i
    Cd i 1
    Ct

九、数组
================================================================================

9.1 dm — 定义数组
  语法: dm 数组名 大小
  功能: 定义一个整数数组，分配指定大小的空间
  示例:
    dm arr 10

9.2 ds — 写数组元素
  语法: ds 数组名 索引 值
  功能: 将值写入数组指定索引位置
  示例:
    dm arr 5
    ds arr 0 42
    ds arr 1 99

9.3 ff — 读数组元素
  语法: ff 数组名 索引
  功能: 读取数组指定索引的值并打印
  示例:
    dm arr 5
    ds arr 0 42
    ff arr 0    → 打印42

  完整示例:
    dm nums 3
    ds nums 0 100
    ds nums 1 200
    ds nums 2 300
    ff nums 0
    ff nums 1
    ff nums 2

十二、平台三字符（内置变量）
================================================================================

  wuxing启动时自动检测当前平台，设置三个内置变量:
    lin = 1 表示运行在 Linux
    win = 1 表示运行在 Windows
    hun = 1 表示运行在 hundunOS
  当前平台对应的变量=1，其他=0

  用法: 用Xj判断平台，写平台专属代码
  示例:
    Xj lin == 1
    jj "运行在 Linux 上"
    sh "uname -a"
    Xt

    Xj hun == 1
    jj "运行在 hundunOS 上"
    Xt

    Xj win == 1
    jj "运行在 Windows 上"
    Xt

  移植到新平台时，只需修改 宿主/宿主64.s 里 _rt_platform 的返回值:
    1=Linux  2=Windows  3=hundunOS
  解释器和脚本一行不用改。

14.1 Ds — 退出程序
  语法: Ds
  功能: 立即退出解释器
