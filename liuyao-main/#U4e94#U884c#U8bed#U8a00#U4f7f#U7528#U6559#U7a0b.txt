================================================================================
                        五行(WuXing) 语言使用教程
                    （完整版 wuxing_full.ly / 36指令）
================================================================================

文件类型: .wx （解释型脚本语言）
解释器: wuxing （六爻语言写的解释器，零依赖）
哲学: 金木水火土，五行相生相克

================================================================================
一、设计哲学
================================================================================

五行是六爻写的交互式解释器，零依赖，可直接运行脚本。
五行对应五种基本类型，以单字标识:

  金(J) = 数值    木(M) = 指针    水(S) = 字节
  火(H) = 结构    土(T) = 空

五行相生: 金生水 水生木 木生火 火生土 土生金
五行相克: 金克木 木克土 土克水 水克火 火克金

================================================================================
二、运行方式
================================================================================

  ./wuxing 脚本.wx

  示例:
    echo 'jj "Hello!"' > t.wx
    ./wuxing t.wx

四、变量
================================================================================

4.1 定义/赋值
  tj 变量名 = 值
  tm 变量名 = 值    （tj的别名）
  td 变量名 = 值    （tj的别名）

  示例:
    tj x = 5
    tj name = 100
    tm y = x ht 3

4.2 复合赋值（m字头）
  mj 变量 = 值    变量 += 值   （加法）
  mm 变量 = 值    变量 -= 值   （减法）
  ms 变量 = 值    变量 *= 值   （乘法）
  md 变量 = 值    变量 /= 值   （除法，除零保护）

  示例:
    tj i = 0
    mj i = 1      # i = i + 1
    ms i = 2      # i = i * 2

================================================================================
五、输出（j字头）
================================================================================

5.1 打印字符串
  jj "字符串"

  示例:
    jj "Hello, World!"
    jj "五行运行成功"

5.2 打印数值/变量
  jj 变量名
  jj 表达式

  示例:
    tj x = 42
    jj x

5.3 打印并清零
  jm 变量 = 表达式

  先打印变量当前值，然后将变量置0。

  示例:
    tj x = 10
    jm x = 0      # 打印10，然后x=0

================================================================================
六、数学表达式
================================================================================

表达式中支持以下运算符（六爻风格两字母）:

  ht  加法 (+)
  hz  减法 (-)
  hh  乘法 (*)
  hl  除法 (/)
  hm  取模 (%)

  示例:
    tj x = 3 ht 4 hh 2     # x = 3 + 4 * 2 = 11
    tj y = 10 hz 3         # y = 7
    tj z = 10 hl 3         # z = 3
    tj w = 10 hm 3         # w = 1

  注意: 表达式从左到右求值，无运算符优先级（先算先得）。
        如需优先级，请拆成多行或用变量中转。

================================================================================
七、比较运算（s字头）
================================================================================

比较结果存入第一个参数（变量），1为真，0为假。

  sj 结果变量 a b    a == b   （相等）
  sm 结果变量 a b    a != b   （不等）
  ss 结果变量 a b    a > b    （大于）
  sd 结果变量 a b    a < b    （小于）
  st 结果变量 a b    a >= b   （大于等于）

  示例:
    tj a = 5
    tj b = 3
    sj r a b       # r = (a == b) = 0
    ss r2 a b      # r2 = (a > b) = 1

================================================================================
八、条件分支（X字头 if/else）
================================================================================

  Xj 条件      if 开始（条件为真执行，为假跳到Xt）
  Xm 条件      else if（条件为真执行，为假跳到Xt）
  Xt           if/else 块结束

  示例:
    tj x = 10
    Xj x > 5
      jj "x大于5"
    Xm x > 3
      jj "x大于3但不大于5"
    Xt
    jj "结束"

  注意: Xj/Xm 条件为假时，跳到匹配的 Xt。
        支持嵌套。

================================================================================
九、循环
================================================================================

9.1 for循环（C字头）
  Cj 变量 = 初值    初始化
  Cm 条件           条件检查（假则跳到Ct）
  Cd 变量 = 增量    增量（循环体结束后执行）
  Ct               循环结束（跳回Cm）

  示例:
    Cj i = 0
    Cm i < 10
      jj i
      jj " "
    Cd i = 1
    Ct

9.2 while循环（d字头）
  ds 条件      while 开始（条件为真循环，假则跳到结束）

  示例:
    tj i = 0
    ds i < 5
      jj i
      mj i = 1
    # while 没有显式结束标记，条件假时跳过下一行

  注意: ds 条件为假时跳过紧跟的下一行（循环体）。
        多行循环体需要配合 Xj/Xt 或其他结构。

9.3 循环控制（D字头）
  Dj           break（跳出当前循环）
  Dm           continue（继续下一次循环，空操作自然继续）

  示例:
    Cj i = 0
    Cm i < 10
      Xj i == 5
        Dj
      Xt
      jj i
    Cd i = 1
    Ct

================================================================================
十、函数（t字头 + d字头）
================================================================================

10.1 定义函数
  ts 函数名()    函数定义开始
    函数体
  tt             函数定义结束

  示例:
    ts 加一()
      tj r = 0
      # 函数逻辑
    tt

10.2 调用函数
  dj 函数名()

  示例:
    dj 加一()

10.3 函数返回
  dm 返回值      设置返回值并结束函数

  示例:
    ts 平方()
      tj x = 5
      dm x hh x     # 返回25
    tt

  注意: 函数参数通过全局变量传递。
        函数返回值存在 g_ret_val，当前版本未直接暴露给调用者。

十一、系统交互（s字头 + D字头）
================================================================================

11.1 执行shell命令
  sh "命令"

  示例:
    sh "ls -la"
    sh "echo hello"
    sh "unzip main.zip"

11.2 退出程序
  Ds 退出码      退出程序
  Dd 返回值      退出并设置返回值

  示例:
    Ds 0          # 正常退出
    Dd 1          # 异常退出，返回1

十二、完整指令速查表（36指令）
================================================================================

【j字头 输出】
  jj  打印字符串/数值
  jm  打印变量并清零

【t字头 变量/函数】
  tj  变量赋值
  tm  变量赋值（别名）
  ts  函数定义开始
  td  变量赋值（别名）
  tt  函数定义结束

【m字头 复合赋值】
  mj  += 加法
  mm  -= 减法
  ms  *= 乘法
  md  /= 除法

【s字头 比较/shell】
  sh  执行shell命令
  sj  == 相等
  sm  != 不等
  ss  >  大于
  sd  <  小于
  st  >= 大于等于

【d字头 控制/函数调用】
  dj  调用函数
  dm  函数返回
  ds  while循环
  dd  if条件（单行）

【C字头 for循环】
  Cj  for初始化
  Cm  for条件
  Cs  占位（空操作）
  Cd  for增量
  Ct  for结束

【X字头 if/else】
  Xj  if开始
  Xm  else if
  Xs  占位（空操作）
  Xt  if/else结束

【D字头 控制】
  Dj  break
  Dm  continue
  Ds  退出程序
  Dd  退出并返回值

十三、编译五行解释器
================================================================================

五行解释器本身是用六爻语言写的，需要用六爻编译器编译:

  步骤1: ./lyc -c -对象 wuxing_full.ly -o wuxing.o
  步骤2: python3 工具/小链接.py wuxing.o wuxing
  步骤3: ./wuxing 脚本.wx

  完整示例:
    ./lyc -c -对象 wuxing_full.ly -o wuxing.o
    python3 工具/小链接.py wuxing.o wuxing
    echo 'jj "Hello!"' > t.wx
    ./wuxing t.wx

十五、五行 vs 六爻 区别
================================================================================

  +----------+----------+----------+
  |          |   六爻    |   五行    |
  +----------+----------+----------+
  | 类型     | 编译型    | 解释型    |
  | 后缀     | .ly       | .wx       |
  | 工具     | lyc编译器 | wuxing解释器 |
  | 哲学     | 八卦64卦  | 金木水火土 |
  | 用途     | 系统级编程 | 脚本/交互 |
  | 速度     | 快(原生)  | 慢(解释)  |
  | 依赖     | 需编译    | 零依赖    |
  | 指令数   | 64关键字  | 36指令    |
  +----------+----------+----------+

  关系: 五行解释器本身是用六爻写的
        六爻编译 → wuxing二进制 → 运行.wx脚本

十六、常见问题
================================================================================

Q: 五行和六爻是什么关系?
A: 六爻是编译型语言，五行是解释型语言。五行解释器本身是用六爻写的。
   先有六爻编译器，编译出wuxing解释器，然后用wuxing运行.wx脚本。

Q: 五行脚本报错?
A: 确保 wuxing 二进制已编译。运行 ./wuxing 脚本.wx
   如果报"没有那个文件或目录"，先编译:
   ./lyc -c -对象 wuxing_full.ly -o wuxing.o
   python3 工具/小链接.py wuxing.o wuxing

Q: 表达式有运算符优先级吗?
A: 没有。表达式从左到右求值。如需优先级，拆成多行用变量中转。

Q: 函数怎么传参数?
A: 当前版本通过全局变量传参。调用前设置全局变量，函数内读取。

Q: jj打印字符串会自动换行吗?
A: 不会。需要换行用 jj "" （打印空字符串，实际是输出空）或 sh "echo"。
