  一、循环一律用【无限循环 + 条件跳出】

      ✅ 推荐（更六爻 —— 两个卦各干各的）
          nn {                    @ nn 震震 循环开头
              nr 条件 { ns }       @ nr 雷山 条件分支   ns 雷水 循环跳出
              循环体
          }

      ⚠️ 兼容但别用（旧写法，当初为和 stage0 对齐才留的）
          nn 条件 { 循环体 }

      理由：六爻表里 nn 就是「循环开头」、ns 就是「循环跳出」，
            是两个不同的卦，本来就该分开用。


  二、算术一律用卦，不打符号

      ht 加    hz 减    hh 乘    hn 除    hf 取模
      hs 位与  hr 位或  hd 位异或      << >> 移位

      ✅  列 = 列 ht 1
      ⚠️  列 = 列 + 1        （兼容，但别用）


  三、注释一律用 rd（行内，后面整段中文给人看）

      rd 三角 —— 打印 1 / 12 / 123
      行 = 行 ht 1        rd 这一行是给人看的说明

      （@ 和 # 兼容保留）


  四、类型一律用五行（首字母缩写）

      J 金 4 字节    M 木 8 字节（指针）    S 水 1 字节
      H 火 4 字节（结构体）    T 土 4 字节（空）
      JJ JM JS … TT（5×5 = 25）

      ✅  tz 行: J = 1
      ⚠️  tz 行: u32 = 1     （老名字，兼容保留）

      ★ 中文（金木水火土）只在文档里，编译器不认。


  五、符号一律用数字标点（两位一组）

      01 (    02 )    03 "    04 "    05 ;
      06 换行    07 {    08 {    09 }
      （00 不用了 —— 注释归 rd）


  六、名字和括号之间可以有空格

      tt 主 0102 -> u32 08        →  tt 主 () -> u32 {

      09
