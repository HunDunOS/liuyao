  一爻      = 1 位
  一个六爻  = 6 位 = 64 种
  3 字节    = 24 位 = 正好 4 个六爻        ← 机器码的天然分组

  一个六爻 = 上卦（干什么）+ 下卦（对什么干），8 × 8 = 64


────────────────────────────────────────────────────────────────────
  一、八卦字母（先天序）
────────────────────────────────────────────────────────────────────

      t = 111 = 7   天 乾
      z = 110 = 6   泽 兑
      h = 101 = 5   火 离
      l = 100 = 4   雷 震
      f = 011 = 3   风 巽
      s = 010 = 2   水 坎
      r = 001 = 1   山 艮
      d = 000 = 0   地 坤

  取【象的拼音首字母】，八个都是单字母 → 定长 → 字节流能顺畅解回来。
  （山用 r 不用 sh：山 shān 和水 shuǐ 会撞；山儿化 = shānr，取那个 r）


────────────────────────────────────────────────────────────────────
  二、六十四卦 = 64 条指令
────────────────────────────────────────────────────────────────────

  【t_ 声明类】                      【z_ 函数类】
    tt  乾乾  定义函数                 zt  泽天  调用函数
    tz  乾兑  定义变量                 zz  兑兑  返回值
    th  乾离  定义常量                 zh  泽火  递归调用
    tn  乾震  定义结构体               zn  泽雷  回调函数
    tf  乾巽  定义数组                 zf  泽风  闭包
    ts  乾坎  定义指针                 zs  泽水  匿名函数
    tr  乾艮  定义类型别名             zr  泽山  方法调用
    td  乾坤  导入模块                 zd  泽地  系统调用

  【h_ 运算类】                      【n_ 控制类】
    ht  火天  加法                     nt  雷天  无条件跳转
    hz  火泽  减法                     nz  雷泽  相等跳转
    hh  离离  乘法                     nh  雷火  不等跳转
    hn  火雷  除法                     nn  震震  循环开头
    hf  火风  取模                     nf  雷风  循环继续
    hs  火水  位与                     ns  雷水  循环跳出
    hr  火山  位或                     nr  雷山  条件分支
    hd  火地  位异或                   nd  雷地  开关分支

  【f_ 输入类】                      【s_ 输出类】
    ft  风天  读键盘                   st  水天  写屏幕
    fz  风泽  读文件                   sz  水泽  写文件
    fh  风火  读内存                   sh  水火  写内存
    fn  风雷  读端口                   sn  水雷  写端口
    ff  巽巽  读数组                   sf  水风  写数组
    fs  风水  读结构体                 ss  坎坎  写结构体
    fr  风山  读指针                   sr  水山  写指针
    fd  风地  读常量                   sd  水地  写日志

  【r_ 结构类】                      【d_ 数据类】
    rt  山天  进入作用域               dt  地天  整数
    rz  山泽  退出作用域               dz  地泽  浮点数
    rh  山火  类型转换                 dh  地火  字符
    rn  山雷  类型检查                 dn  地雷  布尔值
    rf  山风  引用                     df  地风  数组字面量
    rs  山水  解引用                   ds  地水  结构体字面量
    rr  艮艮  空操作                   dr  地山  空值
    rd  山地  注释                     dd  坤坤  字符串


────────────────────────────────────────────────────────────────────
  三、表外两个附加关键字（用户定的，64 格满了，单独列）
────────────────────────────────────────────────────────────────────

    qj    全局变量          —— 在文件顶层声明全局
    wx    危险块            —— 里面才允许裸指针解引用 / 取地址

  ★ 这两个不是六爻，是六爻之外的附加关键字。用。


────────────────────────────────────────────────────────────────────
  四、数字标点（把符号也换成数字）
────────────────────────────────────────────────────────────────────

    00  #   注释标记（只认行首）
    01  (   左括号
    02  )   右括号
    03  "   左引号
    04  "   右引号
    05  ;   语句结束
    06      换行 / 分隔符
    07  \   代码块开始
    08  {   左花括号
    09  }   右花括号

  ★ 用【两位数】，因为单位数容易出错。
  ★ 表里没有的符号（= , : 等）不替换，照常打。
  ★ 扫描规矩：抓一整串连续数字，两位一组从左往右切；
     这一组在 00..09 里就是标点，不在就原样吐（数字字面量）。
