==============================
六爻语言 入门教程（从0开始）
==============================

【六爻是什么】
极简系统级编程语言，只有三样东西：
  8个字母：t z h l f s r d（变量名/函数名只能用这些）
  9个数字标点：01-09（代替所有常规符号）
  64条指令：双字母组合（tt tz ht ll st dd...）

【数字标点对照表】
  01 = (   02 = )   03 = "   04 = "
  05 = ;   06 = /   07 = \   08 = {   09 = }
  注意：字符串内换行用 07，不是 \n

【第一个程序】hello.ly
──────────────────────
tt 主0102 -> u32 08
    rd 这是注释
    st dd 03 hello liuyao 07 04
    zz 0
09
──────────────────────
编译运行：./lyc hello.ly
输出：hello liuyao

逐行解释：
  tt 主0102 -> u32 08   定义函数，参数空，返回u32，代码块开始
  rd ...                  注释
  st dd 03 ... 04         输出字符串
  zz 0                    返回0
  09                      代码块结束

【变量和运算】
  定义：tz 变量名 初始值
    tz h 10
    tz f 0
  赋值：变量名 = 表达式
    h = h ht 1     （ht=加）
    f = h hz f     （hz=减）
  运算：ht加 hz减 hh乘 hl除 hf取模
  输出：st dt 变量（输出整数）  st dd 03 字符串 04（输出字符串）

【循环】
  ll 08
      lz 变量 终止值 08 ls 09   相等则跳出
      变量 = 变量 ht 1
  09
  示例：输出1到10
  ──────────────────────
  tz h 1
  ll 08
      lz h 11 08 ls 09
      st dt h
      h = h ht 1
  09
  ──────────────────────

【条件分支】
  lz 变量 值 08 ... 09   相等则执行
  lh 变量 值 08 ... 09   不等则执行
  示例：判断奇偶
  ──────────────────────
  tz f 0
  f = h hf 2
  lz f 0 08
      st dd 03 even 07 04
  09
  lh f 0 08
      st dd 03 odd 07 04
  09
  ──────────────────────

【常见错误（必看）】
  1. 中文变量名 → 错：tz 计数 0  对：tz h 0
  2. 常规花括号 → 错：{ }  对：08 09
  3. 常规引号 → 错："hi"  对：03 hi 04
  4. 字符串\n → 错：03 hi\n04  对：03 hi 07 04
  5. @注释 → 错：@ comment  对：rd comment
  6. 顶层直接08 → 错：08 ... 09  对：tt 主0102 -> u32 08 ... 09
  7. z当变量名 → 错：tz z 10  对：tz h 10（z是保留字）
