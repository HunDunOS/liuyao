  六爻 × 五行 —— 谁管什么（定稿）
  记于 2026-10-11
════════════════════════════════════════════════════════════════════

  六爻（小写两字母） = 64 条【指令】   「做什么」
  五行（大写）       = 5 单字 + 25 配对 = 【类型名】  「多大 / 什么东西」

  ★★ 编译器【只认首字母缩写】—— 中文只是文档里给人看的，编译器不认。
     写代码一律用 J M S H T 和 JJ JM JS … TT，不要写 金 木 水 火 土。

  六爻表里【还没实现】的那些，用五行来接 —— 尤其是「d_ 数据类」8 条。


────────────────────────────────────────────────────────────────────
  一、五行单字 = 5 个基本类型
────────────────────────────────────────────────────────────────────

      金 J   4 字节    数值
      木 M   8 字节    指针 / 引用
      水 S   1 字节    字节 / 字符
      火 H   4 字节    复合（结构体）
      土 T   4 字节    空 / 无

  ★ 尺寸看【第一个字】，所以下面 25 个配对也都按首字定尺寸。


────────────────────────────────────────────────────────────────────
  二、五行配对 = 25 格（首字 大类 × 次字 细分）
────────────────────────────────────────────────────────────────────

         金      木      水      火      土
   金   金金    金木    金水    金火    金土
   木   木金    木木    木水    木火    木土
   水   水金    水木    水水    水火    水土
   火   火金    火木    火水    火火    火土
   土   土金    土木    土水    土火    土土

  拉丁写法一一对应：JJ JM JS JH JT / MJ MM MS MH MT / SJ … / TJ … TT


────────────────────────────────────────────────────────────────────
  三、六爻表「d_ 数据类」8 条 → 落到五行（这就是"没做的用五行"）
────────────────────────────────────────────────────────────────────

      六爻         五行         编译器里写   说明
      ──────────────────────────────────────────────
      dt 地天 整数     J        (金 值 4 字节)
      dz 地泽 浮点数   JS       (金水 · 浮)
      dh 地火 字符     S        (水 1 字节)
      dn 地雷 布尔值   SJ       (水金 · 0/1)
      df 地风 数组字面量 MH     (木火 · 引用复合)
      ds 地水 结构体字面量 H    (火 · 复合)
      dr 地山 空值     T        (土 · 空)
      dd 坤坤 字符串   M        (木 · 引用，字符串是指针)


────────────────────────────────────────────────────────────────────
  四、六爻表里别的没实现的（用现有方式表达，不需要新码）
────────────────────────────────────────────────────────────────────

      zt 调用函数    →  直接写  名字(参数…)
      tf 定义数组    →  语法    名字[8]: 类型
      ts 定义指针    →  语法    *类型  / 五行 木
      tr 类型别名    →  还没做
      td 导入模块    →  还没做   ← 自举到最后一定要（编译器要分文件）
      ft…fd 输入类   →  内建函数  键() 端入() 读8() …
      st…sd 输出类   →  内建函数  印() 绘点() 写8() …
      rt…rd 结构类   →  运算符    ^ 解引用   @ 取地址   rt/rz 作用域（还没做）
      nt nz nh 跳转  →  编译器自己生成，源码层不写


────────────────────────────────────────────────────────────────────
  五、现在能这么写
────────────────────────────────────────────────────────────────────

      qj 整数: J            @ 就是 qj 整数: u32
      qj 串:   M            @ 指针
      qj 字节: S            @ u8
      qj 结构: H
      qj 空:   T

      tt 主() -> T {
          tz a: J  = 3
          tz b: JS = 4
          tz p: MH = "指针"
          印(a ht b)        @ 源码里一个符号都没有
          zz 0
      }


────────────────────────────────────────────────────────────────────
  六、算术也全是六爻（源码零符号）
────────────────────────────────────────────────────────────────────

      ht 加   hz 减   hh 乘   hn 除   hf 取模
      hs 位与  hr 位或  hd 位异或
      优先级：ht/hz = 9，hh/hn/hf = 10（和 + - * / % 一致）
