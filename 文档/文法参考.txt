==============================
六爻语言 文法参考（64条指令）
==============================

【8字母】t z h l f s r d
  变量名、函数名只能由这8个字母组成，长度不限。
  注意：单字母 z 不能当变量名（保留字）。

【9数字标点】
  01 (   02 )   03 "   04 "   05 ;
  06 /   07 \   08 {   09 }

【函数定义】
  tt 函数名0102 -> 返回类型 08
      函数体
      zz 返回值
  09
  示例：tt 主0102 -> u32 08 ... zz 0 09

【变量定义】
  tz 变量名 初始值
  示例：tz h 10

【赋值】
  变量名 = 表达式
  示例：h = h ht 1

【运算指令（h_类）】
  ht = 加(+)   示例：d = h ht f
  hz = 减(-)   示例：d = h hz f
  hh = 乘(*)   示例：d = h hh f
  hl = 除(/)   示例：d = h hl f
  hf = 取模(%) 示例：d = h hf f

【控制指令（l_类）】
  ll 08 ... 09           无限循环（需配合lz跳出）
  lz 变量 值 08 ... 09   变量==值时执行
  lh 变量 值 08 ... 09   变量!=值时执行
  ls                      跳出当前循环
  zz 值                   函数返回

【输出指令（s_类）】
  st dd 03 字符串 04     输出字符串
  st dt 变量              输出整数

【注释】
  rd 注释内容             单行注释，到行尾
