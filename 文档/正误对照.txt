==============================
六爻语言 正确写法 vs 错误写法
==============================

【1. 函数定义】
  正确：tt 主0102 -> u32 08 ... zz 0 09
  错误：tt 主() -> u32 { ... return 0; }
  错误：08 ... 09（顶层不能直接代码块）

【2. 变量名】
  正确：tz h 10
  错误：tz 计数 10（中文）
  错误：tz count 10（英文）
  错误：tz z 10（z是保留字）

【3. 标点】
  正确：08 09 03 04 01 02 05
  错误：{ } " " ( ) ;
  说明：六爻只用数字标点，不用任何常规符号

【4. 字符串】
  正确：st dd 03 hello 07 04
  错误：st dd "hello\n"
  错误：st dd 03 hello\n04（\n要写成07）

【5. 注释】
  正确：rd 这是注释
  错误：@ 这是注释
  错误：// 这是注释
  错误：/* 注释 */

【6. 循环】
  正确：
    ll 08
        lz h 11 08 ls 09
        st dt h
        h = h ht 1
    09
  错误：
    for (h=1; h<=10; h++) { printf("%d", h); }
  错误：
    while (h < 11) { print h; h++; }

【7. 条件】
  正确：
    lz f 0 08
        st dd 03 even 07 04
    09
    lh f 0 08
        st dd 03 odd 07 04
    09
  错误：
    if (f == 0) { printf("even\n"); } else { printf("odd\n"); }

【8. 运算】
  正确：d = h ht f
  错误：d = h + f
  正确：d = h hz f
  错误：d = h - f
  正确：d = h hh f
  错误：d = h * f

【9. 输出】
  正确：st dt h（输出整数）
  错误：printf("%d", h)
  正确：st dd 03 hello 04（输出字符串）
  错误：printf("hello")

【10. 返回】
  正确：zz 0
  错误：return 0;

【总结口诀】
  字母只用 tzhlfsrd
  标点只用 01到09
  指令全是双字母
  注释用 rd
  循环用 ll
  条件用 lz/lh
  运算用 ht/hz/hh/hl/hf
  输出用 st dt/st dd
  返回用 zz
