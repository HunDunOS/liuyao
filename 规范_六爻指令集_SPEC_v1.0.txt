标点替换:
00 = # 01 = (        02 = )        03 = "        04 = '        05 = ;
06 = /        07 = \        08 = {        09 = }

03 是开串（双引号），04 是闭串（单引号）。
字符串内部直接写 03 即可输出双引号，无需转义。
07 就是反斜杠 \，没有任何转义机制。

================================================================================
【t_ 声明类】
tt  乾乾  定义函数
tz  乾兑  定义变量并分配栈内存
th  乾离  定义只读常量
tl  乾震  定义结构体蓝图
tf  乾巽  定义连续数组
ts  乾坎  定义全局变量 (Global Var)
tr  乾艮  定义枚举类型 (Enum)
td  乾坤  定义布尔类型 (Bool)

【z_ 函数类】
zt  泽天  调用函数
zz  兑兑  返回/弹栈帧
zh  泽火  标签定义 名:
zl  泽雷  函数指针/回调
zf  泽风  获取变量/内存地址 (Address Of)
zs  泽水  内联汇编块 (Inline Asm)
zr  泽山  断言/抛异常
zd  泽地  系统调用 (Syscall)

【h_ 运算类】
ht  火天  加法 (+)
hz  火泽  减法 (-)
hh  离离  乘法 (*)
hl  火雷  除法 (/)
hf  火风  取模 (%)
hs  火水  位与 (&)
hr  火山  位或 (|)
hd  火地  位异或 (^)

【l_ 控制类】
lt  雷天  无条件跳转 (Goto)
lz  雷泽  相等则跳转 (Je)
lh  雷火  不等则跳转 (Jne)
ll  震震  循环开始/条件判断 (While)
lf  雷风  循环递增/继续
ls  雷水  跳出循环 (Break)
lr  雷山  条件分支 (If)
ld  雷地  开关分支/跳转表 (Switch)

【f_ 输入类】
ft  风天  读键盘 (Stdin)
fz  风泽  读文件流 (File Read)
fh  风火  读内存地址 (Mem Read)
fl  风雷  读硬件 IO 端口 (In)
ff  巽巽  读数组元素
fs  风水  读结构体成员
fr  风山  解引用 (Dereference)
fd  风地  逻辑非 (!)

【s_ 输出类】
st  水天  写屏幕 (Stdout)
sz  水泽  写文件流 (File Write)
sh  水火  写内存地址 (Mem Write)
sl  水雷  写硬件 IO 端口 (Out)
sf  水风  写数组元素
ss  坎坎  写结构体成员
sr  水山  指针写入 (Pointer Write)
sd  水地  调试/日志输出 (Log)

【r_ 内存类】
rt  山天  进入作用域 {
rz  山泽  退出作用域 }
rh  山火  强制类型转换
rl  山雷  运行时类型检查
rf  山风  内存清零 (Memset)
rs  山水  释放内存 (Free)
rr  艮艮  申请堆内存 (Malloc)
rd  山地  内存拷贝 (Memcpy)

【d_ 数据类】
dt  地天  整数字面量 (含字符/布尔/空)
dz  地泽  浮点数字面量
dh  地火  左移 (<<)
dl  地雷  右移 (>>)
df  地风  数组字面量
ds  地水  结构体字面量
dr  地山  按位取反 (~)
dd  坤坤  字符串字面量
