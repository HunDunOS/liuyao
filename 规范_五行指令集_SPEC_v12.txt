【五行核心矩阵 5×5 = 25 格】（数据类型、内存与高级抽象）
================================================================================

【j 金系】（全功能 I/O 与文本流）
jj  金金  打印字符串/对象 (Print)
jm  金木  格式化输出 (Format/Printf)
js  金水  获取用户输入 (Input)
jh  金火  文件全量读取 (ReadFile)
jt  金土  文件写入与追加 (Write/Append)

【m 木系】（数据结构与序列化）
mj  木金  字符串切片/分割/替换 (String Ops)
mm  木木  列表/数组操作 (List: Push/Pop/Sort)
ms  木水  字典/哈希表操作 (Dict/Map)
mh  木火  JSON/XML 序列化与解析 (Serialize)
mt  木土  强类型转换与检测 (Int/Float/Bool)

【s 水系】（系统底层与并发控制）
sj  水金  执行系统 Shell 命令并捕获返回 (Popen)
sm  水木  环境变量与命令行参数 (Env/Args)
ss  水水  系统时间戳/日期格式 (Time)
sh  水火  目录遍历与文件系统操作 (OS.Walk)
st  水土  线程/协程锁/信号量 (Lock/Semaphore)

【h 火系】（面向对象与元编程）
hj  火金  定义函数/方法 (Def)
hm  火木  函数返回/生成器 yield (Return/Yield)
hs  火水  异常捕获与处理 (Try-Catch)
hh  火火  定义类与继承 (Class/Object)
ht  火土  导入外部模块/动态库 (Import/Link)

【t 土系】（高级内存与正则）
tj  土金  变量声明与赋值 (Var)
tm  土木  正则表达式匹配与提取 (Regex)
ts  土水  上下文管理器 (With)
th  土火  引用/解引用与弱引用 (Ref/WeakRef)
tt  土土  垃圾回收/手动内存释放 (GC/Free)

================================================================================
【四季控制矩阵 4×5 = 20 格】（逻辑与生命周期）
================================================================================

【C 春系】（迭代与循环）
Cj  春金  for 循环开始
Cm  春木  循环条件判断
Cs  春水  循环步进 (i++)
Ch  春火  遍历迭代器/生成器 (For-each)
Ct  春土  循环体结束

【X 夏系】（分支与模式匹配）
Xj  夏金  if 条件判断
Xm  夏木  else if 多分支
Xs  夏水  else 默认分支
Xh  夏火  match/switch 模式匹配
Xt  夏土  分支结束

【Q 秋系】（全栈网络通信）
Qj  秋金  HTTP GET 请求
Qm  秋木  HTTP POST 请求/上传
Qs  秋水  文件下载/断点续传
Qh  秋火  URL 解析/请求头伪造
Qt  秋土  原生 Socket/TCP/UDP 通信

【D 冬系】（异步与进程）
Dj  冬金  跳过当前循环 (break)
Dm  冬木  继续下一次循环 (continue)
Ds  冬水  退出程序 (exit)
Dh  冬火  异步/协程 (Async/Await)
Dt  冬土  启动子进程/多进程 (Process)
