# 六爻语言 (LiuYao)

极简主义、文化驱动、全链路自研的系统级编程语言。

## 快速开始

```bash
gcc 编译器/lyc.c -o 构建/中间/lyc
./lyc 示例/入门01_hello.ly
```

输出：`hello liuyao`

## 语言规范

### 8字母（变量名/函数名）
`t 天` `z 泽` `h 火` `l 雷` `f 风` `s 水` `r 山` `d 地`
注意：单字母 `z` 是保留字，不能当变量名。

### 9数字标点
`01 (` `02 )` `03 "` `04 "` `05 ;` `06 /` `07 \` `08 {` `09 }`

### 64条指令（8类×8条）
- **t_ 声明**：tt函数 tz变量
- **h_ 运算**：ht加 hz减 hh乘 hl除 hf取模
- **l_ 控制**：ll循环 lz相等 lh不等 ls跳出 zz返回
- **s_ 输出**：st屏幕(dt整数/dd字符串)
- **rd**：注释

## 特色

- **原生64位**：直接输出 x86-64 机器码，不经汇编器(as)、不经链接器(ld)
- **零依赖**：静态链接 ELF，不依赖 libc
- **编译极快**：<0.1秒完成编译+链接+运行
- **全链路自研**：编译器+编码器+链接器+运行时全部自己写
- **数字标点**：源码只用 01-09 数字标点，不用常规符号
- **为写系统而生**：精确可控，每一条指令都对应最终机器码
