# 五行(WuXing) 脚本语言解释器

## 简介
脚本解释型语言，V12 终极满编矩阵，45指令 + 环境检测。

## 标点替换
```
01 = (    02 = )    03 = "    04 = "    05 = ;
06 = /    07 = \    08 = {    09 = }    00 = #
```

## 核心矩阵 5×5 = 25 格
