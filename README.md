# 六爻/八卦 语言编译器

## 简介
纯命令式编译语言，x86-64 裸奔，64指令全满，纯血数字编码。

## 标点替换（00-09 纯血宪法）
```
00 = #    01 = (    02 = )    03 = "    04 = "
05 = ;    06 = /    07 = \    08 = {    09 = }
```

## 编译
```
cc -O2 -o lyc lyc.c
./lyc -c -对象 源.ly -o 输出.bin
python3 工具/小链接.py 输出.bin 可执行文件
```
